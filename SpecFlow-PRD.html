Product Requirements Document

SpecFlow

面向 PM 与独立开发者的 AI 产品设计工具
通过自然语言对话，产出可交互的 HTML 产品方案——
原型 + PRD + Spec + 项目骨架 + 质量规则融为一体，

Problem

PM 与开发之间的产品信息在 Figma、Notion、飞书文档间碎片化流转；AI 编程工具缺乏结构化上下文，"vibe coding" 质量无保证；传统 PRD 文字墙无人愿读。

Solution

通过对话生成融合原型+PRD+Spec 的 HTML 产品方案；内置设计系统物料库与质量规则引擎；通过 MCP 协议将 Spec 实时注入 AI 编程工具，实现"Spec 持续保鲜"。

Core Features

核心功能模块

九层能力架构，覆盖从对话到上线的全链路

F1 · Chat Studio — 对话驱动设计

核心 v1.0

自然语言描述需求 → AI 实时生成可交互 HTML 预览 + 结构化 Spec

核心交互

  • • 左侧：多轮对话面板，支持上下文连续引用
  • • 右侧：HTML 实时预览 (iframe sandbox)
  • • 底部：Spec 结构摘要 (页面清单 / 数据模型 / API)
  • • 支持上传产品规划文档 (.docx / .pdf / .md) 初始化
  • • 每轮对话自动沉淀到 spec.json

验收标准

  • ☑ 首次对话后 ≤ 15s 出现可交互预览
  • ☑ Spec 结构实时更新，页面/模型/API 自动索引
  • ☑ 支持对话回滚到任意轮次
  • ☑ 预览 HTML 支持响应式视口切换
  • ☑ 文档上传 ≤ 10MB，自动提取关键信息

F2 · Canvas — 画布精修

v1.0

点选任意元素 → 底部浮动 AI 对话 → 自然语言微调样式/布局/交互

核心交互

  • • 顶部工具栏：选择 / 移动 / 视口切换 / 撤销重做
  • • 左侧：图层面板 (DOM 树可视化)
  • • 中央：WYSIWYG 画布，蓝色选择框 + 拖拽手柄
  • • 底部：浮动暗色毛玻璃 AI 对话条
  • • 右侧：属性面板 (尺寸/色值/字号/间距)

验收标准

  • ☑ 选中元素后高亮 ≤ 100ms
  • ☑ 底部对话支持 "把这个按钮改成圆角蓝色"
  • ☑ 修改实时反映到画布 + 同步回 spec.json
  • ☑ Diff 视图对比修改前后差异
  • ☑ AI 预生成 3 个调整建议供快速选择

F3 · Material Hub — 设计物料库

v1.0

Design Token 模板 + 动画交互库 + 组件模式库，解决"AI 设计缺少品味"

Design Token 模板

  • • 15+ 预设配色方案 (SaaS / 电商 / 内容 / 金融)
  • • 完整色阶 (50-900) + 语义色
  • • 字体排版梯度 (xs → 6xl)
  • • 间距 / 圆角 / 阴影体系
  • • 一键应用到当前项目

动画交互库

  • • 入场动画 (fade / slide / scale / blur)
  • • 滚动触发 (reveal / parallax / sticky)
  • • 微交互 (hover lift / ripple / skeleton)
  • • 页面切换 (crossfade / slide / morph)
  • • 实时预览 + 参数可调

组件模式库

  • • 按钮 → 5 种形态 + 加载/禁用态
  • • 表格 → 排序/分页/虚拟滚动
  • • 表单 → 校验/错误/分步
  • • 导航 → 侧栏/面包屑/标签页
  • • 弹窗 → modal/drawer/popover

F4 · HTML PRD — 可交互需求文档

v1.0

人读 HTML + 机读 spec.json，告别"文字墙 PRD 没人愿看"

HTML PRD 包含内容

  • • 产品概览 + 关键指标 (嵌入式仪表盘)
  • • 站点地图 (可视化页面树)
  • • 页面详情 + 内嵌原型 iframe
  • • 数据模型 (可展开实体关系)
  • • 状态机图 (订单/用户生命周期)
  • • 设计系统 (实时 Token 预览)
  • • API 契约 (展开式 JSON 示例)
  • • 开发进度追踪

vs 传统 PRD

✕Notion/飞书长文档 → 单页交互式 HTML
✕Figma 链接跳转 → 原型内嵌预览
✕表格描述数据模型 → 可交互 ER 图
✕手动更新进度 → 自动进度条

F5 · Project Base — 可运行项目启动包

v1.5

git clone → npm run dev → 立刻能跑，含 Next.js + Tailwind + shadcn/ui + BaaS

项目骨架内容

  • • .cursorrules / CLAUDE.md — AI 编程规则
  • • docs/ — PRD.md + spec.md + design-system.md
  • • src/ — 路由 / 组件 / hooks / API 骨架
  • • supabase/ — DDL + RLS + Seed 数据
  • • __tests__/ — E2E + 单元测试骨架
  • • .github/ — CI/CD workflow 配置

BaaS 集成

  • • Supabase：Auth + Database + RLS + Storage
  • • PocketBase：轻量替代方案
  • • Spec 数据模型 → DDL 自动生成
  • • 权限模型 → RLS 策略自动生成
  • • 预置用户注册/登录/密码重置

F6 · Quality Rules Engine — 工程质量引擎

v2.0 NEW

PM 描述"做什么"，Spec 自动补"怎么做才对"——性能 / 测试 / 安全 / 规范全透明内置

三级质量预设

Quick MVP — 基础验证 + 输入校验
Production Ready — 完整错误处理 + E2E + 性能预算 + 安全防护
Enterprise — 审计日志 + RBAC + 可观测性 + CI/CD

四大支柱

性能优化 — RSC 划分 / 代码分割 / 图片优化 / 列表虚拟化
自动化测试 — Spec → E2E 用例 + Zod schema + API 测试骨架
安全防护 — RLS / XSS / CSRF / Rate Limiting 开箱即用
代码规范 — 文件行数限制 / 三态强制 / TypeScript strict
